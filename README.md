## 🎯 درباره افزونه

**CS Admin Hide Menu** یک افزونه سبک و سریع از تیم **CodSoft** است که به مدیران سایت اجازه می‌دهد منوهای اضافی یا مزاحم پنل مدیریت وردپرس را با یک کلیک مخفی کنند — بدون دست‌زدن به کد و بدون نیاز به دانش فنی.

این افزونه مخصوص کسانی است که:
- 🎨 می‌خواهند پنل مدیریتشان تمیز و ساده باشد
- 🔒 می‌خواهند منوهای حساس را از چشم سایر کاربران دور نگه دارند
- ⚡ می‌خواهند سرعت بارگذاری پنل ادمین را افزایش دهند
- 🧹 از شلوغی منوهای غیرضروری خسته شده‌اند

## 🚀 نصب

### روش ۱: نصب از پنل وردپرس (توصیه‌شده)

1. فایل ZIP افزونه را از [سایت CodSoft](https://codsoft.ir) دانلود کنید
2. وارد پنل وردپرس شوید
3. به **افزونه‌ها → افزودن → بارگذاری افزونه** بروید
4. فایل ZIP را انتخاب و روی **نصب** کلیک کنید
5. روی **فعال‌سازی** کلیک کنید

### روش ۲: نصب دستی (FTP)

1. فایل ZIP را دانلود و استخراج کنید
2. پوشه `cs-admin-hide-menu` را در مسیر `/wp-content/plugins/` آپلود کنید
3. از پنل وردپرس به **افزونه‌ها** بروید و افزونه را فعال کنید

---

## 🎬 نحوه استفاده

1. بعد از فعال‌سازی، به **تنظیمات → مخفی‌سازی منوها** بروید
2. لیست تمام منوهای ادمین را با آیکون می‌بینید
3. تیک منوهایی که می‌خواهید مخفی شوند را بزنید
4. روی **ذخیره تغییرات** کلیک کنید
5. تمام! منوها بلافاصله مخفی می‌شوند

### ↩️ برگرداندن منوها

نگران نباشید! منوهای مخفی‌شده همیشه در لیست باقی می‌مانند. کافی است:
1. دوباره به **تنظیمات → مخفی‌سازی منوها** بروید
2. تیک منو را بردارید
3. ذخیره کنید
